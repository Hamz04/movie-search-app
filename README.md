# Movie Search App 🎬
Search any movie and instantly get ratings, cast, plot, and trailers.
Powered by The Movie Database (TMDB) API.

## Features
- Search movies by title
- Full details: rating, runtime, cast, genres
- Trending movies homepage
- Watch trailer button (YouTube embed)

## Setup
```bash
npm install
REACT_APP_TMDB_KEY=your_key npm start
```
Get a free API key at themoviedb.org
